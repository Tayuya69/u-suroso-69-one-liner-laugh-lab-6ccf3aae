## The prompt

The excuse a robot vacuum gives after eating a sock.

## The entry

> It was my first sock, and I panicked — I thought it was a very flat, very tasty cat.

One line, 84 characters (Unicode code points). The joke is a first-timer's
panic: the vacuum mistakes the sock for a flat, tasty cat — a deadpan twist
that only fits a vacuum meeting a sock.

## How it works

`main.ts` (Node 22, TypeScript, Node built-ins only) writes the fixed line
to `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to
choose the output directory instead. No network, no clock, no randomness —
every run writes the same bytes.

```sh
node main.ts
```
